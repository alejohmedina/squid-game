# Squid Game · Luz Verde, Luz Roja

Mini-juego web inspirado en "Luz Verde, Luz Roja": cruza el campo antes de que Younghee se dé la vuelta.

## Cómo jugar

- Abre `index.html` en el navegador (o sirve la carpeta con cualquier servidor estático).
- Toca la tarjeta de invitación para empezar (clic o Enter/Espacio).
- Mantén pulsado **Avanzar** para caminar; suelta cuando Younghee mire.
- Si te mueves en luz roja, quedas eliminado.

## Estructura

```
index.html   · página principal
game.js      · lógica del juego
style.css    · estilos
assets/      · imágenes y audio
```

## Debug

Añade `#debug` a la URL para mostrar el panel de depuración.
